# SENTINEL

A one-page internet prank.

The page starts completely white and displays the Hypergamy graphic. The first click starts the music and an escalating stream of simulated Rickroll windows.

## Development

- Node.js 22+
- `npm install`
- `npm run dev`

## Cloudflare

This project uses Next.js with OpenNext for Cloudflare Workers.

- `npm run preview`
- `npm run deploy`

The Worker name and compatibility settings are kept in `wrangler.jsonc`.
