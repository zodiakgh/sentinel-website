What a real dashboard needs

This site runs on GitHub Pages, which only serves static files. A dashboard would additionally require:

  1. A server-side application that keeps the Discord OAuth2 client secret private.
  2. A secure API between that application and the bot, with authorisation checks per server.
  3. Hosting for that backend, separate from this static site.

The folder structure of this site leaves room for a dashboard page, but no controls are wired up.
