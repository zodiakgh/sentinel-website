Installation & invitation

PLACEHOLDER

The bot’s public invitation link is not configured on this website. The bot code does not contain its application ID, so a valid link cannot be built here. Ask in the support server for the current link. Site owner: see assets/js/config.js.

Add Sentinel to your server ↗

  1. You need the Manage Server permission on the server you want to add Sentinel to.
  2. Open the official invitation link only from this site or the support server, and check that it asks for the scopes bot and applications.commands.
  3. Choose your server, review the permissions and authorise.
  4. In Server Settings → Roles, drag the Sentinel role above the roles it must manage and below your staff roles.
  5. Run /utility help, then follow the configuration section below.

Privileged intents

The bot requests the Server Members, Message Content and Presence intents (used for welcome events, AutoMod, leveling and status-based roles). They must be enabled for the application in the Discord Developer Portal, and Discord requires approval of privileged intents once a bot is in 100 or more servers. This matters to the bot operator, not to server administrators.

Permissions

Who can run what

Many admin commands declare a required member permission (usually Manage Server). It is shown as a “Requires” badge in the command directory. Server owners can further restrict commands in Server Settings → Integrations.

Configuration

Sentinel is configured from inside Discord. Start with /panelsetup for the configuration dashboard, then set up the modules you need:

  1. Security first: /verify setup, /automod setup, /antinuke setup.
  2. Welcome: /welcome setup.
  3. Support: /ticket setup, then /ticket diagnose.
  4. Community: /levelset settings, /economy panel, /tempvoice setup.
  5. Test in a private channel before announcing changes (/automod test, /flow test).

The command prefix defaults to ! for the commands that also work as prefix commands.

Troubleshooting

Slash commands do not appear

Check the bot was added with the applications.commands scope, that you have the “Use Application Commands” permission in the channel, and wait a little: the bot registers its commands globally when it starts.

“Missing permissions” or the bot cannot act on someone

Compare the command’s “Requires” badge with your permissions, and make sure the Sentinel role sits above the target role or member in the role list.

Music does not play

Music needs a reachable Lavalink node. Administrators can run /music admin status, /music admin nodes and /music admin diagnostics. Make sure the bot can Connect and Speak in your voice channel.

AutoMod does not react

Run /automod status and /automod diagnostics. Check whether the module is in monitor mode (it only logs), whether the member, role or channel is exempt, and whether the Message Content intent is enabled for the bot.

Tickets, verification or notifications misbehave

Use /ticket diagnose, /verify config and /notify status to see the current configuration and errors. Social notifications depend on external platforms that can throttle or block requests.

Still stuck? Contact support.

FAQ

Not yet. Configuration happens in Discord through interactive panels; see the Dashboard page.

Which languages does the bot support?

The code supports English and French for its language setting, and the ticket system ships with both languages. Many other messages are in English only.
