ModerationAvailable

Day-to-day moderation commands: kick, ban, unban, mute, unmute, warn (with a stored warning history), softban, bulk message clearing, channel lock/unlock, slowmode, nickname and role changes.

Getting started
Staff use /moderation subcommands; they are also available as prefix commands (default prefix !).
Requirements
The bot needs the matching Discord permission (Ban Members, Kick Members, Manage Messages, Manage Roles, etc.).
/moderation

AutoModAvailable

A rule engine with 10 modules: anti-spam, anti-flood, mention protection, link protection, invite protection, content filters, anti-raid, scam protection, account security and edit monitoring. Each module can log, delete, warn, time out, kick, ban or quarantine, with escalation, exemptions, presets, an incident log and statistics. A monitor mode detects and logs without punishing.

Getting started
Run /automod setup, then tune modules in /automod panel. Use /automod test to preview what a sample message would trigger before enabling punishments.
Requirements
Message Content intent. A log channel is chosen during setup. Data is kept in the bot’s automod.json.
/automod

AntiNukeAvailable

Rate-based protection against destructive actions. 10 protection modules watch channel deletion/creation/changes, role deletion/creation/changes, bans, kicks, webhook creation and bot additions; each has its own threshold and time window (for example 3 channel deletions within 10 seconds by default).

Getting started
Open the panel with /antinuke setup, toggle modules and edit thresholds.
Requirements
Uses the server audit log; the bot should be placed high in the role list so it can act.
/antinuke

Security Center & HoneypotAvailable

The Security Center offers a status overview and a server lockdown that locks text channels for the default role, then restores what it changed with /security unlock. The honeypot is a trap channel: any normal user message posted there is treated as a trigger and removed automatically.

Getting started
/security setup, /security lockdown; /honeypot setup creates or selects the trap channel.
Requirements
Manage Channels / Manage Roles for lockdown; Manage Messages for the honeypot.
/security/honeypot

VerificationAvailable

Gate your server behind a verification button. Configure a verified role and an unverified role, a verification channel and category, a log channel, a custom panel title/description and button text. Options include blocking bots, a minimum account age, a minimum time in the server and DMing users.

Getting started
/verify setup walks through the steps; /verify panel posts the panel; /verify config shows the current setup.
Requirements
Manage Roles and Manage Channels. Verification is disabled until you configure it.
/verify

Installation & invitation

Add Sentinel to your server ↗

  1. You need the Manage Server permission on the server you want to add Sentinel to.
  2. Open the official invitation link only from this site or the support server, and check that it asks for the scopes bot and applications.commands.
  3. Choose your server, review the permissions and authorise.
  4. In Server Settings → Roles, drag the Sentinel role above the roles it must manage and below your staff roles.
  5. Run /utility help, then follow the configuration section below.

Privileged intents

The bot requests the Server Members, Message Content and Presence intents (used for welcome events, AutoMod, leveling and status-based roles). They must be enabled for the application in the Discord Developer Portal, and Discord requires approval of privileged intents once a bot is in 100 or more servers. This matters to the bot operator, not to server administrators.

Permissions

Sentinel works best with the permissions its features use. The simplest option is Administrator; to follow least privilege, grant only what the modules you enable need:

FeatureDiscord permissions
ModerationBan Members, Kick Members, Moderate Members, Manage Messages, Manage Roles, Manage Nicknames, Manage Channels
AutoModManage Messages (delete), Moderate Members (timeout), Kick/Ban Members, Manage Roles (quarantine), Manage Channels (lockdown)
AntiNukeView Audit Log, Ban/Kick Members, Manage Roles, Manage Channels, Manage Webhooks
Verification / rolesManage Roles, Manage Channels
Tickets / TempVoice / HoneypotManage Channels, Manage Messages
MusicConnect, Speak, View Channel
EverywhereView Channel, Send Messages, Embed Links, Attach Files, Use Application Commands

Who can run what

Many admin commands declare a required member permission (usually Manage Server). It is shown as a “Requires” badge in the command directory. Server owners can further restrict commands in Server Settings → Integrations.

Configuration

Sentinel is configured from inside Discord. Start with /panelsetup for the configuration dashboard, then set up the modules you need:

  1. Security first: /verify setup, /automod setup, /antinuke setup.
  2. Welcome: /welcome setup.
  3. Support: /ticket setup, then /ticket diagnose.
  4. Community: /levelset settings, /economy panel, /tempvoice setup.
  5. Test in a private channel before announcing changes (/automod test, /flow test).

The command prefix defaults to ! for the commands that also work as prefix commands.

Troubleshooting

Slash commands do not appear

Check the bot was added with the applications.commands scope, that you have the “Use Application Commands” permission in the channel, and wait a little: the bot registers its commands globally when it starts.

“Missing permissions” or the bot cannot act on someone

Compare the command’s “Requires” badge with your permissions, and make sure the Sentinel role sits above the target role or member in the role list.

Music does not play

Music needs a reachable Lavalink node. Administrators can run /music admin status, /music admin nodes and /music admin diagnostics. Make sure the bot can Connect and Speak in your voice channel.

AutoMod does not react

Run /automod status and /automod diagnostics. Check whether the module is in monitor mode (it only logs), whether the member, role or channel is exempt, and whether the Message Content intent is enabled for the bot.

Tickets, verification or notifications misbehave

Use /ticket diagnose, /verify config and /notify status to see the current configuration and errors. Social notifications depend on external platforms that can throttle or block requests.

Still stuck? Contact support.

Is there a web dashboard?

Not yet. Configuration happens in Discord through interactive panels; see the Dashboard page.

Which languages does the bot support?

Sentinel supports English and French for its language setting, and the ticket system ships with both languages. Many other messages are in English only.
