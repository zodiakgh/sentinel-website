Commands & controls.

Everything you need to run a music session in Discord. This reference describes the initial Sentinel Music command set.

Slash commands

CommandWhat it does
/playSearch for a track or play a supported URL.
/panelPost or reopen the interactive music player.
/queueDisplay the current queue.
/nowplayingShow details for the current track.
/volumeAdjust playback volume.
/leaveDisconnect the player from the voice channel.
/settingsView or change available music settings.

Interactive player

The Discord player is designed around the controls that matter during playback:

  • Pause and resume the current track.
  • Skip to the next track.
  • Stop playback and clear the active session.
  • Adjust volume and inspect the queue.

Audio & supported sources

Audio filters such as Bass Boost, 8D, Nightcore and equalizer presets depend on the Lavalink plugins installed on the selected node. Search providers also depend on the node configuration and their current availability.

A public Lavalink node may not support every provider or filter. Sentinel should only advertise a source or effect when the connected node confirms that it is available.

Requirements

  • Sentinel Music must be online and have permission to connect and speak in the voice channel.
  • A reachable Lavalink v4 node is required for audio playback.
  • The Lavalink URI and password must be stored as private environment variables. Never post them in a support channel or screenshot.
