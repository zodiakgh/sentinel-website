# Catalog methodology

Last catalog seed: 7 November 2026.

## Eligibility

SENTINEL indexes projects whose source code is distributed under a verifiable open-source license. A repository being public is not enough: the license must be identifiable and linked to its license reference.

The initial 114-entry seed is focused on software that can be downloaded or self-hosted at no cost. Pricing status is stored separately because hosted services, support, or managed deployments can be paid even when the underlying software is open source.

## Sources

For each listing, SENTINEL stores three source records:

1. Official project website
2. Source-code repository or official source hosting
3. License reference, linked to the corresponding SPDX license page

The Awesome Self-Hosted list is used as a discovery index for self-hostable projects, not as the sole proof of licensing. The official project repository and license reference remain the per-listing sources.

- [SPDX License List](https://spdx.org/licenses/)
- [Open Source Initiative — Approved Licenses](https://opensource.org/licenses)
- [Awesome Self-Hosted](https://github.com/awesome-selfhosted/awesome-selfhosted)
