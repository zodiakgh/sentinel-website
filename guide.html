INSTALLATION

Set up Sentinel Music.

Follow these steps to run the Discord bot on your host and connect it to a Lavalink audio node.

SETUP STEPS1 · Discord application2 · Wispbyte host3 · Environment4 · Lavalink node5 · Start & test

1. Create the Discord application

  1. Open the Discord Developer Portal and create an application.
  2. Open the Bot section and create the bot user.
  3. Copy the bot token and keep it private. Do not share it in screenshots, chat or GitHub.
  4. Enable the required intents only if the bot's code asks for them.
  5. Generate an invite URL with the bot and applications.commands scopes and the permissions the bot needs.

2. Prepare Wispbyte

  1. Create a Python server on Wispbyte.
  2. Upload the complete Sentinel Music project files to the server root.
  3. Use the host's dependency installer or run pip install -r requirements.txt.
  4. Set the startup command to python start.py.

3. Configure environment variables

Create a private .env file from the example file included with the project:

DISCORD_TOKEN=your_bot_token
LAVALINK_URI=your_node_host:2333
LAVALINK_PASSWORD=your_node_password
LAVALINK_IDENTIFIER=sentinel-primary
DEFAULT_VOLUME=50
Do not commit .env to GitHub. Make sure .env is listed in .gitignore. Never publish your Discord token or Lavalink password.

4. Connect a Lavalink v4 node

Use a node you operate or a provider you trust. Confirm its Lavalink version, uptime, supported audio sources, plugin list, usage limits and terms before relying on it. A public node can disappear or change its configuration without notice.

5. Start and test

  1. Start the server and check the console for a successful Discord login and Lavalink connection.
  2. Invite the bot to a test server.
  3. Join a voice channel and run /play.
  4. Test /queue, /nowplaying, /volume and /leave.

For help, share the error message after removing all tokens, passwords, node credentials and personal information.
