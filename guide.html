INSTALLATION / 02

Get the music started.

Set up the Discord application, deploy the bot on Wispbyte and connect a Lavalink audio node.

SETUP STEPSDiscord applicationWispbyteEnvironmentLavalink nodeTest playback

1. Create the Discord application

  1. Open the Discord Developer Portal and create an application.
  2. Create its bot user and copy the bot token. Keep this token private.
  3. Generate an invite URL using the bot and applications.commands scopes, with the permissions required for voice and messages.

2. Prepare your Wispbyte server

  1. Create a Python server in your Wispbyte panel.
  2. Upload the Sentinel Music project files to the server.
  3. Install the dependencies listed in the project's requirements.txt.
  4. Set the startup file or command to the entry point included with your project.
Use the actual entry-point filename from your project package. Do not guess it or replace it with a filename from an unrelated tutorial.

3. Add private environment variables

Use the environment-variable manager in your host panel, or a local .env file if the project is configured to load one. Typical values include:

DISCORD_TOKEN=your_bot_token
LAVALINK_URI=your_node_host:2333
LAVALINK_PASSWORD=your_node_password

Never upload a real .env file to GitHub. Add it to .gitignore and never share tokens or passwords in screenshots.

4. Connect a Lavalink v4 node

You can run your own node or use a public provider. Before choosing a public node, check its uptime, version, connection limits, supported audio sources, installed plugins and usage rules. Public nodes can become unavailable or change configuration without notice.

5. Start and test

  1. Start the bot and check the console for Discord login and Lavalink connection errors.
  2. Invite it to a test server and join a voice channel.
  3. Run /play and test queue and player controls.
  4. If it fails, check the bot logs and Lavalink node status. Remove all credentials before sharing logs.
