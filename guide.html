GETTING STARTED / SENTINEL MUSIC

From first test
to your server.

Start Sentinel on your own computer, make sure playback works, then move it to your host. No public credential walkthroughs. No unnecessary setup noise.

01 — LOCAL TEST02 — AUDIO NODE03 — HOSTING
01 / FIRST RUN

Test it on your PC.

The easiest way to verify your bot is working is to run it locally before deploying it.

WINDOWS 10 / 11
01

Install the essentials

Use Python 3.11 or newer, Java 21 for Lavalink, and FFmpeg if your project requires it.

02

Install project packages

Open PowerShell in the Sentinel Music folder and run:

py -m pip install -r requirements.txt
03

Keep configuration private

Set the bot and audio-node credentials using your local private configuration. Never paste secrets into this website, public chats, screenshots or Git commits.

04

Start the services

Start your Lavalink node first, then launch the bot using the entry-point file supplied with your project.

05

Run a playback test

Invite your configured bot to a test server, join a voice channel and try /play. Check the terminal if the bot cannot connect or play audio.

02 / AUDIO

Connect Lavalink.

Sentinel uses Lavalink to handle audio playback. The bot and node must be able to reach each other.

LOCAL NODEDEFAULT PORT
localhostPort 2333

When the bot and Lavalink run on the same PC, configure the bot to connect to your local node. If you use a hosted or public node, use the connection details supplied by that provider instead.

Audio effects depend on the plugins installed on the node. A public node may not support every effect or source.
03 / DEPLOYMENT

Move to hosting.

Once local playback works, you can deploy the same project to Wispbyte or another compatible Python host.

01

Prepare the host

Create a Python server and upload the project files. Install the packages from the included requirements file.

02

Set private configuration

Use your host's private environment-variable settings. Do not upload your local secrets file with the project.

03

Choose your audio node

Use a Lavalink node reachable from your host. A local address such as localhost only works when the node is running in the same environment.

04

Launch and verify

Set the correct startup file, launch the bot and test playback in a voice channel. Keep credentials out of logs before sharing them for support.
