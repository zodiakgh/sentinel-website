Support

Get help with Sentinel.

The Discord support server is the official place to ask questions, report problems and follow updates.

Ask in the support server

Join the server and describe your situation. A good report makes it much faster to help you.

Join the support server ↗

Reporting a problem

  • The exact command you used, for example /ticket setup.
  • What you expected and what happened instead.
  • Any error message shown by the bot (a screenshot is fine).
  • Whether the bot has the permissions listed in the documentation.
SECURITY

Never share your bot token, passwords or API keys, including in support requests. Staff will never ask for them.

Inside Discord

Two commands defined in the bot point to the same support server:

/utility support/utility invite

Contact by e-mail

support@sentineldashboard.site

For account-free questions, e-mail is fine; for faster help, use the support server. This site has no contact form.
